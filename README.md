# قالب Hugo العربي الأزرق (Arabic Blue Hugo Theme)

قالب Hugo متجاوب وجميل يدعم اللغة العربية بشكل كامل مع تصميم أنيق باللون الأزرق السماوي والخلفية الرمادية الفاتحة.

## المميزات

- ✅ **دعم كامل للعربية**: يدعم الكتابة من اليمين إلى اليسار (RTL)
- ✅ **تصميم متجاوب**: يعمل بشكل مثالي على جميع الأجهزة (موبايل، تابلت، كمبيوتر)
- ✅ **ألوان جميلة**: مخطط ألوان أنيق باللون الأزرق السماوي والرمادي الفاتح
- ✅ **سرعة عالية**: محسن للأداء والسرعة
- ✅ **سهولة الاستخدام**: بسيط ونظيف
- ✅ **SEO محسن**: محسن لمحركات البحث
- ✅ **قائمة متجاوبة**: قائمة تنقل تتكيف مع الشاشات الصغيرة

## التثبيت والاستخدام

### 1. إنشاء موقع Hugo جديد
\`\`\`bash
hugo new site my-arabic-site
cd my-arabic-site
\`\`\`

### 2. نسخ القالب
انسخ مجلد `themes/arabic-blue` إلى مجلد `themes` في موقعك.

### 3. تحديث إعدادات الموقع
انسخ محتوى ملف `config.toml` أو قم بتحديث إعداداتك:

\`\`\`toml
baseURL = "http://example.org/"
languageCode = "ar"
title = "موقعي الشخصي"
theme = "arabic-blue"
defaultContentLanguage = "ar"

[params]
  description = "موقع شخصي باللغة العربية"
  author = "اسم المؤلف"
\`\`\`

### 4. إنشاء محتوى
\`\`\`bash
hugo new posts/my-first-post.md
\`\`\`

### 5. تشغيل الموقع
\`\`\`bash
hugo server -D
\`\`\`

## تخصيص الألوان

يمكنك تخصيص الألوان عبر تعديل المتغيرات في ملف `static/css/style.css`:

\`\`\`css
:root {
    --primary-blue: #87CEEB;      /* الأزرق السماوي */
    --secondary-blue: #4682B4;    /* الأزرق الفولاذي */
    --accent-blue: #1E90FF;       /* الأزرق الداكن */
    --light-gray: #F8F9FA;        /* الرمادي الفاتح */
    --medium-gray: #E9ECEF;       /* الرمادي المتوسط */
    --dark-gray: #495057;         /* الرمادي الداكن */
}
\`\`\`
