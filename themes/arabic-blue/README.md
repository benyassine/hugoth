# قالب Hugo العربي المتجاوب

قالب Hugo متجاوب مصمم خصيصاً للغة العربية مع دعم كامل للاتجاه من اليمين إلى اليسار (RTL).

## المميزات

- 🎨 **تصميم متجاوب**: يتكيف مع جميع أحجام الشاشات
- 🌍 **دعم كامل للعربية**: RTL وخطوط عربية جميلة
- ⚡ **سريع وخفيف**: تحميل سريع وأداء ممتاز
- 🎯 **سهل الاستخدام**: واجهة بسيطة وواضحة
- 🎨 **ألوان مخصصة**: أزرق يماوي وخلفية رمادية قريبة للأبيض

## التثبيت

1. قم بتحميل القالب
2. ضعه في مجلد `themes/arabic-blue`
3. قم بتخصيص الإعدادات في `config.toml`

```toml
baseURL = "https://example.org"
languageCode = "ar"
title = "موقعي الشخصي"
theme = "arabic-blue"
```

## التخصيص

### الألوان

يمكنك تخصيص الألوان من خلال تعديل المتغيرات في `static/css/style.css`:

```css
:root {
    --primary-color: #00bcd4; /* أزرق يماوي */
    --background-color: #f8f9fa; /* رمادي قريب للأبيض */
}
```

### القائمة

قم بتخصيص القائمة في `config.toml`:

```toml
[menu]
  [[menu.main]]
    name = "الرئيسية"
    url = "/"
    weight = 1
  [[menu.main]]
    name = "حول"
    url = "/about/"
    weight = 2
```

## الملفات المهمة

- `layouts/_default/baseof.html` - التخطيط الأساسي
- `layouts/_default/index.html` - الصفحة الرئيسية
- `layouts/_default/single.html` - صفحات المقالات
- `layouts/_default/list.html` - صفحات القوائم
- `static/css/style.css` - ملف التنسيقات
- `static/js/main.js` - ملف JavaScript

## المتطلبات

- Hugo 0.60.0 أو أحدث
- متصفح حديث يدعم CSS3 و JavaScript
